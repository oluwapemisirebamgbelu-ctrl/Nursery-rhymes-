# Nextkids

Original English nursery rhymes, songs, and early-learning videos for young children.

## Project goals

- Create original, safe, educational content for children.
- Use original lyrics, recordings, characters, and visual assets wherever possible.
- Build a consistent production workflow for YouTube.
- Keep every upload suitable for parents and preschool learners.

## Repository structure

```text
scripts/       Original song lyrics, narration, and production scripts
production/    Repeatable video-production workflow and checklists
channel/       Titles, descriptions, publishing, and channel guidance
legal/         Copyright, licensing, and Made for Kids notes
assets/        Placeholder folders for original audio, visuals, and thumbnails
```

## Important publishing rules

- Mark videos accurately as **Made for Kids** when they are directed at children.
- Use only music, images, voices, fonts, and footage that Nextkids owns or is licensed to use.
- Do not copy another channel's animation, recording, characters, thumbnail, or script.
- Review YouTube's current policies before applying for monetization.
