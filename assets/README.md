# Nextkids Assets

Store only original or properly licensed project assets here.

Suggested folders:

```text
audio/       Licensed AI voice exports and original music
characters/  Original character artwork
backgrounds/ Original backgrounds
thumbnails/  Final YouTube thumbnails
video/       Local exports before publishing
licenses/    Private records of asset licenses and receipts
```

Do not commit private API keys, passwords, payment details, or unlicensed media to this repository. Keep provider receipts and detailed license documents private if they contain personal or billing information.
